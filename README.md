\# RHConnect — Frontend



Interface utilisateur de la plateforme SaaS RH — ISM Dakar

Projet de fin d'études — Licences GLRS \& CDSD — 2025/2026



\## Stack technique

\- Framework : React 18 / Next.js 14

\- Styling : Tailwind CSS

\- État global : Zustand

\- Appels API : Axios + React Query

\- Tests : Jest + Playwright



\## Installation locale



\### Prérequis

\- Node.js 18+

\- npm 9+



\### Lancer l'application

npm install

npm run dev



Application disponible sur http://localhost:3000
